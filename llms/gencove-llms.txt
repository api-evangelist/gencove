# Gencove

> Gencove is an enterprise analytics platform for low-pass whole genome sequencing (lpWGS). Its REST API (base `https://api.gencove.com/api/v2/`) lets you upload FASTQ/array data, run samples through analysis pipelines, track sample status, download deliverables (including merged VCFs), and receive signed webhook events on analysis completion. Authenticate with a static API key (`Authorization: Api-Key <key>`) or a JWT bearer token.

## APIs
- [Gencove Back API](https://api.gencove.com/api/v2/openapi.json): OpenAPI 3.0.3, 124 paths / 151 operations across projects, samples, pipelines, uploads, batches, BaseSpace/S3 imports, Explorer, and organization/user management.
